## The 90-second story

1. Click Watchcat in the bottom-right corner of VS Code.
2. Point out the physical target `α² = 4.41` and the measured final memory
   population near `4.402` photons.
3. Open **Show convergence math**. Explain that every candidate is compared
   across the full time trace, not only the final point.
4. Point out the transient peak near `6.848` photons and the memory-edge
   population `0.00267`.
5. Explain the key product behavior: Watchcat is **worried** because the
   reference itself is not yet safely truncated. It refuses to recommend a
   cheaper configuration even though `32×10` is close on the selected
   observables.
6. Click **Wigner** to open the measured reduced-memory snapshots. Explain that
   this is visual logical-state evidence, while the warning decision still comes
   from parity, purity, trace, convergence, and Fock-boundary metrics.
7. Click **Explain**. With no Gemini key, the local explanation is deterministic;
   with `GEMINI_API_KEY`, the same evidence is summarized by Gemini.
8. Click **Run sweep** to show that the UI triggers the real Python/Dynamiqs
   pipeline, not a mock animation.

## What to claim

> Watchcat is a numerical trust advisor for dissipative cat-qubit simulations.
> The cat is the interface; the evidence is the product. It checks transient
> Fock-boundary occupation, trace drift, observable convergence, runtime, and
> the semiclassical `α²` target before it ever celebrates a smaller run.

Do not claim a compute saving from the current report. The current result is a
successful warning that the Hilbert space needs to grow.

To demonstrate the optimization state as a second, clearly labeled experiment,
run the preparation-window validation:

```bash
python -m qpet.run_sweep \
  --duration 0.2 --samples 9 \
  --truncations 32x10,48x12,64x16 \
  --no-wigner --out watchcat_early_validation.json
```

It selects `48x12` against a `64x16` reference with the same convergence and
boundary checks. Present it as an early-time validation result; do not call it
a saving for the full 2 microsecond experiment.
